# Пробный запуск ClickBench

В Docker успешно выполнены 43 исходных запроса ClickBench закреплённой ревизии `fa52f8524ad9446695018fda6a415aade3a4ccd9`. Для каждого запроса проведены один прогрев и три измеряемых повтора. В `system.query_log` подтверждены 43 завершённых прогрева и 129 измеряемых запусков без ошибок.

Использованы ClickHouse `26.9.27.3` на ARM64 и таблица `nis_smoke.hits` с [датасетом, полученным отбором по хешу из всех 100 исходных файлов](../clickbench-sample.json). Запросы ограничены двумя потоками и 3 ГиБ памяти. Прогон проверяет выполнение нагрузки и сбор метрик на общем датасете КТ-1; для сравнения физических вариантов предусмотрены отдельные серии на том же наборе.

Материалы находятся в каталоге [прогона](./full/):

- [run.json](./full/run.json) — версия, настройки, ревизия и контрольная сумма нагрузки, число строк входа и статус завершения.
- [queries.sql](./full/queries.sql) — выполненные запросы; файл совпадает с закреплённым оригиналом.
- [measurements.jsonl](./full/measurements.jsonl) — одна запись на измеряемый повтор.
- `qNN-rR.tsv` — ответ запроса `NN` в повторе `R`; например, [ответ первого запроса](./full/q01-r1.tsv).

| Поле измерения | Значение | Единицы |
|---|---|---|
| `query_number`, `repeat` | Номер запроса в SQL-файле и измеряемого повтора | — |
| `query_id` | Идентификатор запроса для связи с журналом ClickHouse | — |
| `elapsed_ms` | Серверная длительность запроса, `query_duration_ms` | мс |
| `read_rows` | Число прочитанных строк по журналу ClickHouse | строки |
| `read_bytes` | Объём прочитанных несжатых данных по журналу ClickHouse | байты |
| `cpu_time_us` | Сумма `UserTimeMicroseconds` и `SystemTimeMicroseconds` | мкс CPU |
| `memory_usage_bytes` | Расход памяти запроса, `memory_usage` | байты |

Проверены наличие всех 129 пар «запрос — повтор», всех файлов ответов и всех пяти метрик, а также совпадение контрольной суммы SQL и числа строк входа с исходными материалами. Для коротких запросов `elapsed_ms` может быть равен нулю из-за миллисекундной точности.

Команды сборки, запуска и получения результатов приведены в [инструкции Docker](../../../docker/checkpoint-1/README.md#пробный-запуск-clickbench).
