# Проверка метрик

Проверка выполнена 02.11.2026 на ClickHouse `26.9.27.3`, Linux/WSL2 x86-64. Docker доступны 16 CPU и около 30,17 ГиБ памяти; запрос ограничен двумя потоками и 3 ГиБ.

Повторно подготовлена выборка из всех 100 частей: 1 000 659 строк, SHA-256 совпал с [манифестом](../clickbench-sample.json). Проверены загрузка и независимый расчёт Python: [input-check.json](./input-check.json), [load-check.json](./load-check.json).

## Запуск

После [подготовки данных](../../../docker/checkpoint-1/README.md#подготовка-данных) выполнены:

```bash
python3 scripts/checkpoint-1/verify.py --artifacts-dir .local/results/participant-3-load-check
python3 scripts/checkpoint-1/measure_probe.py --output-dir artifacts/checkpoint-1/metrics
python3 scripts/checkpoint-1/summarize_metrics.py artifacts/checkpoint-1/metrics
```

Для нового замера запустите `measure_probe.py` без `--output-dir`: будет создан отдельный каталог. Последняя команда повторно формирует сводку без Docker.
