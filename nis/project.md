# Описание проекта

## Назначенное задание

[P12-A. ClickHouse: отсечение данных](https://distsys.ru/osukhoroslov/nis2/src/branch/main/project-tasks/p12-a-clickhouse-data-skipping.md).

## Выбранный технический путь

**Работа с авторским артефактом:** готовый ClickHouse выполняет запросы и хранит данные; ClickBench предоставляет исходную схему, нагрузку и материалы подготовки данных. Команда адаптирует их для уменьшенного набора и двух физических вариантов таблицы, готовит запуск и сбор измерений.

Для стенда используется готовый Docker-образ ClickHouse. Два физических варианта таблицы задаются SQL-определениями с разными ключами сортировки и гранулярностью. Скрипты подготовки данных и сравнения адаптируются для запуска в Docker.
